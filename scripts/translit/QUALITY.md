# Reader transliteration policy and quality gate (#93)

Policy version `local-context-2` applies to the actual Tanakh, Besorah and DSS local generation paths. It uses simplified lowercase reader spelling: English ch / Spanish j for ח and spirant כ; tz for צ; v for consonantal ו; no doubled gemination or vowel length marks. Dagesh controls b/k/p; medial geminated sheva remains vocal. Final ה is retained as h. David is `david`, Abraham `avraham`, Joseph `yosef`, Jerusalem `yerushalayim`, and Jesus `yeshua`, generated by the same pointed rules across books. Unpointed spelling remains a low-information consonantal fallback, not a reconstructed pronunciation.

The H3068 display policy takes precedence over older issue examples: no vocalized divine-name transliteration. The local engine also suppresses the exact divine-name surface with up to three recognized prefixes. It does not turn similarly named lexical entries into divine names.

Contextual rules distinguish initial/final and short-vowel-closing sheva, consonantal pointed yod from unpointed matres, both holam placements, reduced qamats and qamats qatan, and final furtive patah. Maqaf becomes a hyphen; spaces remain boundaries; cantillation and punctuation are omitted. Morphological slash markup is omitted. The already-merged Bani `is_silent_sheva` implementation is reused instead of maintaining a competing sheva classifier.

## Resource evaluation

The repository already vendors Charles Loder's `hebrew-transliteration` 2.9.1 under `tools/bani/research/hebrew-transliteration`, including its MIT license, source, schemas and documentation. Its scholarly syllabification/schema support is useful reference material and underlies the Bani schema work. Directly replacing this Python generation path would require a Node bridge and separate Spanish reader-style adaptation. The vendored snapshot is explicitly reference material, not maintained by Davar; this assessment does not claim it is the latest upstream version.

The chosen bounded approach reuses the maintained local Bani sheva rule and retains the existing reader orthography, with contextual fixes measured by an explicit fixture. No external API, AI correction stage or newly inferred vocalization is introduced. Cached DSS vocalization remains subject to the existing consonant-preservation gate. Ambiguous unpointed input is not upgraded to confident pronunciation.

## Benchmark and baseline

`data/translit/benchmark.json` contains 26 curated words/phrases (16 Tanakh, 10 Besorah), categorized by failure class. The intended spellings were specified before changing the engine. It includes Genesis 1:1 and Matthew 1:1 phrase fragments, DSS maqaf, names and sacred-name policy. Some synthetic/minimal forms isolate rules; this is not a random corpus sample or a measured corpus accuracy estimate.

The original PR's six expected strings repeated existing errors (including `uve`, `mitzevah`, and divine-name pronunciation). Those are not retained as policy. On the new, identical 26-case fixture, baseline engine exact matches are 9/26 (34.62%); corrected engine 26/26 (100%). Per-case actual outputs are retained in `data/translit/reports/local-baseline.json` and `local-final.json`. Baseline engine revision: `5542a23aa6ece89962e4ffbed4875b8b4c459c6b`.

The gate requires exact English AND Spanish matches, rejects empty/duplicate-identity fixtures, and independently tests both corpora. Normalized scores are diagnostic only and cannot hide missing word boundaries. CI runs the same gate. Known-good cases, sacred-name suppression and a deliberately incorrect expectation test guard against false-green scoring.

## Generation integration

The per-book writer now uses a deterministic generator version instead of the wall-clock timestamp. An integration test caught and fixes a prior aliasing bug: clearing a word after policy filtering could clear the same dictionary returned unchanged by the policy. Both Tanakh and Besorah tests retain text/identity and the normal transliteration while omitting H3068 display fields. DSS output uses this same corrected engine; explicit editorial overrides remain authoritative.

Run `python -m scripts.translit.benchmark data/translit/benchmark.json --fail-under 1.0` and `python -m pytest -q tests/test_translit_benchmark.py tests/test_dss_transformation.py tools/bani/tests`.

Regeneration verification: all 39 Tanakh books and 27 Besorah books were generated twice with identical bytes (306,784 Tanakh and 109,767 Besorah word identities retained). All 26 existing DSS output books were also regenerated twice identically. No source Hebrew text or external AI cache was modified.
